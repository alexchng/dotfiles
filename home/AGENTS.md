# Agent Instructions

This is an Airlift workspace.

Before you start work, read `~/.claude/CLAUDE.md`. That file tells you how to work in the Airlift environment. It covers:

- Environment limits (ephemeral container, no bash sandbox).
- How to install and run runtimes with `mise`.
- GitLab access with `glab`.
- How to expose an app with `airlift proxy`.
- Other `airlift` commands (git setup, credentials, MCP, changelog).

Follow the instructions in that file. If this file and `~/.claude/CLAUDE.md` do not agree, use `~/.claude/CLAUDE.md`.
